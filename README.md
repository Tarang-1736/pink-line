# Pink Line | Jaipur Heritage Edition 🌸🏰

A secure, women-only ride-sharing application concept developed as a BCA project. This app features a unique Rajasthani aesthetic, blending modern security with the heritage of the "Pink City."

## ✨ Features
* **Live Geolocation:** Automatically centers on the user's current location in Jaipur.
* **Heritage UI:** Terracotta Pink theme with Mandala art and Bandhani patterns.
* **Secure Auth:** Persistent sessions and user validation using LocalStorage.
* **SOS Safety:** Instant emergency alert system for local authorities.

## 🛠️ Tech Stack
* **Frontend:** React.js, Tailwind CSS
* **Mapping:** Leaflet.js (OpenStreetMap)
* **Storage:** Browser LocalStorage
* **Fonts:** Playfair Display & Montserrat
